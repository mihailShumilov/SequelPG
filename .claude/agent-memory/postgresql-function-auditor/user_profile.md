# User Profile

The user is building SequelPG, a native macOS PostgreSQL client:
- Stack: Swift 5.9+, SwiftUI, macOS 13+, PostgresNIO as database driver
- Architecture preference: strict MVVM with actor-based services, mock-friendly protocols
- Testing approach: unit tests with MockDatabaseClient actor — no live DB required
- Code style: SwiftFormat enforced, Conventional Commits, 4-space indent, 120-char max width
- Cares about correctness, SQL injection safety, and proper quoting of all SQL constructs
